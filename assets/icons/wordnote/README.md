# WordNote card icons

Source: https://www.figma.com/design/Xl6kzzGQWxUHHpjG8oBhB7/WordNote?node-id=86-699

The PNG exports preserve the complete 48 × 48 Figma icon frames, including
padding and rotation. Render them at 48 × 48 using `WordnoteIcons` from
`src/constants/wordnote.ts`.

| Asset | Figma node |
| --- | --- |
| back.png | 86:702 |
| chevron-down.png | 75:227 |
| previous.png | 86:711 |
| edit.png | 86:712 |
| next.png | 86:714 |

The SVG files are the original inner vectors for reuse. Their intrinsic
dimensions differ from the complete icon frames; they are not drop-in
replacements for the PNGs.

Palette: `WordnoteColors` in `src/constants/wordnote.ts`.
Font: `assets/fonts/Inter/Inter.ttf`, with its license in `OFL.txt`.
Inter is sourced from https://github.com/google/fonts/tree/main/ofl/inter.
